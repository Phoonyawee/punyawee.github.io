# Phoonyawee Portfolio

Personal portfolio of **Phoonyawee Namwong**, an IT developer experienced in ERP systems, databases, and web development.

## Live site

[punyawee-github-io.vercel.app](https://punyawee-github-io.vercel.app)

## Sections

- About
- Experience
- Skills
- Projects
- Education
- Contact

## Tech stack

- Next.js 16
- React 19
- Tailwind CSS 4
- Sass

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Portfolio content

Personal information, experience, education, skills, and projects are stored in `utils/data/`.
